## About Me

I'm an **AI engineer and researcher**, and a Computer Science graduate from **E-JUST**, specializing in artificial intelligence.

I build **retrieval systems, LLM applications, cloud data pipelines, and full-stack software**, with a focus on developing reliable, production-ready solutions.

My research interests include **Arabic NLP safety, hybrid GraphRAG architectures, and efficient LLM adaptation**. I also work with **biosignal analysis and computer vision**.

**Education:** BSc in Computer Science (AI Specialization) — E-JUST
