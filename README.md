I specialize in building production-grade machine learning architectures and cloud data pipelines — bridging domain-specific data with scalable AI systems. ## Systems & Research

### [Ibn-Baz Knowledge Assistant](https://github.com/AbdelrahmanAboegela/Ibn-Baz)
*Arabic RAG Architecture & Citation Grounding*
- Domain-specific hybrid RAG pipeline grounded in fatwa archives, Quranic texts, and Hadith references.
- Implements specialized vector retrieval, voice verse search, and strict citation constraints for verified factual output.

### [GraphRAG Multiview](https://github.com/AbdelrahmanAboegela/graphrag-multiview)
*Graph-Enhanced Retrieval & Intent Routing*
- Hybrid RAG framework combining Neo4j graph structures with dense vector search.
- Intent-aware query routing for complex, multi-hop reasoning across connected knowledge bases.

### [D-Mask](https://github.com/AbdelrahmanAboegela/D-Mask)
*LLM Safety Research — Adversarial Arabic Diacritics*
- Reproducibility artifact for a sparse, base-letter-invariant Arabic diacritic attack on LLM safety guardrails.
- Demonstrates systemic vulnerability in multilingual safety classifiers across fine-tuned model families.

### [ArGuard](https://github.com/AbdelrahmanAboegela/ArGuard-2026-tasks)
*Arabic Content Safety Evaluation*
- Evaluation pipeline for Arabic-specific safety guardrails and adversarial content filtering benchmarks.

### [Cloud Data Engineering Pipeline](https://github.com/AbdelrahmanAboegela/DEPI-Final-Data-Engineering-Task)
*Enterprise Azure Data Infrastructure*
- End-to-end ETL pipeline using Azure Data Factory, Databricks, and Synapse Analytics.
- Multi-stage ingestion, transformation, and analytical data warehousing for production-scale workloads.

### [EEG/ECG Stress Detection](https://github.com/AbdelrahmanAboegela/Depi-Graduation-Project)
*Multimodal Biosignal Classification*
- Trained multimodal models on EEG and ECG data streams for real-time stress level classification.

### [Egyptian License Plate Recognition](https://github.com/AbdelrahmanAboegela/egyptian_alpr_yolov11)
*Two-Phase YOLOv11 Computer Vision Pipeline*
- Designed a two-phase detection and recognition pipeline for Egyptian ALPR using YOLOv11.
